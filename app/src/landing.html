The 0.90 rule, in three numbers

How it works

Three lanes, and the model is only trusted with one of them.

  1. Score

    Enter one application, or upload the day's intake CSV. The team's cleaning rules run first: incomes above ₹6 lakh are treated as annual, blank incomes get the job-type median.

  2. Triage

    Auto-decline only when the model is at least 90% sure and the applicant has a bureau score. Analyst review for everything else. Analyst only for applicants with no credit history.

  3. Keep the record

    Save your threshold as a policy, keep up to 50 scorings and 5 intake files, re-open them later, and every save, delete and policy change is logged.

Limitations

Read these before trusting a single score.

  • It copies past decisions, not repayment.The model learned what analysts decided. Any mistakes or bias in those decisions are built in.
  • Weak for new-to-credit applicants.Right only 56.7% of the time without a bureau score, so those applicants always go to a person.
  • One bank, six months, simulated data.Trained on April–September 2026. Re-test on newer applications before any live use.
  • Fairness needs watching.Gender is not an input, but income and job type can stand in for it. Check the fairness monitor every month.
  • Only the bank's file format.Batch files need the same 13 columns as the bank's application data. Other datasets are rejected, not guessed at.
  • Coursework, not a lending system.Built for Calibo AI Academy MUC02 (Batch 10, Path 2, KLU). It makes no decision about real people.
